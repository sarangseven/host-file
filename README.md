# Sarang S — Portfolio (master source)
Static site: open `index.html` in a browser. No build step.
- Edit links (résumé points to your Google Drive link) at the top of `script.js`.
- Replace `assets/avatar.jpg` and `assets/bengaluru.jpg` with higher-resolution originals (same file names).
- Theme: light on first visit; the toggle (top-left) saves the choice.
- Free hosting: drag this folder onto Netlify Drop, or push to GitHub and enable Pages.

## v2 notes
- Fonts are self-hosted in `assets/fonts` (Inter + Space Mono); no Google Fonts requests. System SF Pro is used first on Apple devices.
- Images are WebP. Scroll reveals respect reduced-motion settings.
